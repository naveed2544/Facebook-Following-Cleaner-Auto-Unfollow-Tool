# Facebook-Following-Cleaner-Auto-Unfollow-Tool
Facebook Following Cleaner is a simple Chrome extension that helps you manage your Facebook Following list. It automatically processes followed profiles and pages one by one until the list is completed or you manually stop the process.

The extension includes Start All, Remove Next, Pause, Resume, and Stop controls. You can run it without an extra delay or select a custom delay between unfollow actions. It also displays removed and error counters so you can track progress.

Main Features:

• Automatically unfollows profiles and pages one by one
• Continues until the Following list is completed
• Start, Pause, Resume, and Stop controls
• Optional delay between unfollow actions
• Automatic scrolling and loading of more accounts
• Removed and error progress counters
• Does not use Unfriend or Block actions
• Simple and easy-to-use interface

Open your Facebook Following list, launch the extension, choose your preferred delay, and press Start All.
